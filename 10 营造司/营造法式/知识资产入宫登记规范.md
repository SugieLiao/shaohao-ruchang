# 知识资产入宫登记规范

## 一、知识资产进入流程

```text
候选资产
   ↓
宫主审核
   ↓
确定宫房
   ↓
营造司施工
   ↓
PR 审核
   ↓
Merge 入宫
```

知识资产必须依次完成候选登记、宫主审核、宫房确认、文件施工、PR 审核和 Merge，方可视为正式入宫。

## 二、资产登记字段

| 字段 | 登记要求 |
|---|---|
| 资产编号 | 用于唯一识别知识资产的编号。 |
| 资产名称 | 能够准确表达资产主题的名称。 |
| 来源 | 记录资产的原始材料、讨论、研究或实践来源。 |
| 所属宫房 | 记录经宫主确认的目标宫房。 |
| 核心内容 | 概述资产沉淀的主要知识。 |
| 为什么重要 | 说明资产对投资研究、交易实践或知识体系的价值。 |
| 关联经历 | 记录与资产有关的实践、案例或形成背景。 |
| 当前状态 | 使用本规范定义的状态进行登记。 |

## 三、状态定义

| 状态 | 定义 |
|---|---|
| 候选 | 已提出资产线索，等待宫主审核。 |
| 已批准 | 宫主已批准入宫，并确认建设方向。 |
| 建设中 | 营造司正在进行文件建设与版本施工。 |
| 已入宫 | 资产已经通过 PR 审核并 Merge。 |
| 待迭代 | 资产已经入宫，但仍有明确内容需要后续完善。 |
