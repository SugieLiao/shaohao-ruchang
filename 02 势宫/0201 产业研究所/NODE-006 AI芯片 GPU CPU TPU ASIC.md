## Step 0 路由记录

宫主点名"Node：AI芯片（GPU, CPU, TPU, ASIC）"——路由表分诊：**部分命中**。NODE-003（华为超节点）报告已含昇腾 910C/950 的系统级分析，但本点名范围为**全市场计算芯片层**（全球 GPU/TPU/ASIC + 国产 GPU/CPU 全梯队），远超 NODE-003 的"超节点内部视角"。按 NODE-002 确立协议，**宫主点名 = 批准**，登记为 NODE-006（第 5 次复用：002 前驱体 → 003 超节点 → 004 OCS → 005 oDSP → 006 AI芯片）。

**切分说明（新范式）**：NODE-003 是系统级 Node，其外部 BOM 已切出"互连层"（NODE-004 OCS、NODE-005 oDSP，经 REL-007/REL-010 三步切分定型）。本 Node 是同一系统级 BOM 分解的另一半——**计算层**。至此超节点 BOM 两大价值层（计算/互连）均独立成 Node：NODE-006 与光互联三兄弟构成姊妹层，剩余候选为存储（HBM 已有 NODE-001）、电源/液冷、整机。

## 九问

### Step 1 范围与市场规模（多口径并存）

市场：全球 + 中国 AI 算力芯片（云端训练/推理加速芯片 + 配套服务器 CPU），A 股映射优先。

| 口径 | 数据 | 来源 |
| --- | --- | --- |
| 全球 AI 算力芯片 | 2026 年 1870 亿美元（+31.7%），推理侧首超训练达 54% | IIM 报告（B 级） |
| 全球加速器出货 | 2026E 1515 万颗 → 2027E 2267 万颗；2027 ASIC 12.5M vs GPU 10.9M | 大摩/摩根大通（B 级转引） |
| 中国 AI 加速卡市场 | 2024 年 2164.77 亿元 → 2028 年约 1.11 万亿元 | 灼识咨询（B 级转引） |
| 中国 AI 服务器芯片 | 2026 年 120 亿美元（+65%） | 集邦咨询（B 级） |

注意灼识（加速卡整机口径，数千亿元级）与集邦（芯片口径，百亿美元级）相差一个数量级——**前者含板卡/整机溢价**。延续"给区间、标来源"原则：芯片口径中国约 800-1200 亿元/年，增速 50-65%。

**暗线 3 检查点**：三重结构性驱动（禁运下的国产替代 + 训练转推理的 ASIC 化 + 主权 AI 资本开支），周期属性弱——**结构性为主，Alpha 应持有**；但估值层已部分透支（见 Step 7/8）。

### Step 2 系统变化：三股力量同时改写芯片层

1. **禁运改写中国格局**：美国 4 月起 H100/H200 输华需商务部许可，黄仁勋公开承认英伟达"已基本让出中国市场"（Bernstein：份额 66%→8%）。英伟达自身指引对中国贡献归零——**真空由国产填补：华为系 46%→56%，互联网自研 ASIC 20%→23%**。需求侧反向确认：国内三家头部 CSP 2026 资本开支 2000 亿/1200 亿/3800 亿量级。
2. **推理时代改写全球格局**：2026 年推理算力需求首超训练（54%）。推理负载持续、高频、成本敏感——云厂商有强烈 TCO 动机用专用 ASIC 替代高价通用 GPU。大摩模型中 **2027 年谷歌 TPU 出货量（817 万颗，36%）反超英伟达（752 万颗，33.2%）**——AI 芯片史上首次交接信号。
3. **制造约束改写国产格局**：这是中国市场最特殊的一股力量——需求 420 万颗 vs 中芯 N+2 产能 260 万颗，**四成需求物理上造不出来**。芯片设计公司从"技术竞赛"退化为"产能排队竞赛"：拿不到配额的厂商连参赛资格都没有。

**暗线 1（受损方）**：①英伟达在华基本盘（H200 个别审批=不确定性而非机会）；②通用 GPU 阵营：2027 年起 ASIC 出货反超，通用 GPU 增速 16% vs ASIC 44.6%；③**无产能配额的二线国产设计公司**——N+2 排队即淘汰，海光/摩尔/壁仞/沐曦/天数/燧原十余家争抢不足一半产能；④对冲方向：智能体（Agentic AI）拉动通用计算，**服务器 CPU 反而受益**（海光 CPU 逻辑、英伟达 Vera CPU 配比变化印证）。

### Step 3 价值链与 BOM 分级

价值链：云厂商/CSP（资本开支） → 整机（浪潮/曙光/华为） → **计算芯片（英伟达/TPU/昇腾/寒武纪/海光/摩尔/沐曦…）** → 制造（中芯 N+2 / 台积电） + HBM（NODE-001） + 先进封装 + EDA/IP（芯原）。

AI 服务器 BOM 价值分级（暗线 5）：

| 层级 | 环节 | BOM 占比 | 分级 | 可投性 |
| --- | --- | --- | --- | --- |
| 1 | 加速芯片（GPU/TPU/ASIC） | 70-80% | **超重要** | 全球双雄不在 A 股；A 股十多家排队 |
| 2 | HBM | 每卡 128-196GB，占卡成本 30-40% | 超重要 | 已有 NODE-001 专研 |
| 3 | 服务器 CPU | 1:2 至 1:4 配比 | 重要 | 海光（x86）独大，智能体增量逻辑 |
| 4 | 网络/互连（光模块+交换） | 智算中心增量主战场 | 重要 | NODE-004/005 已覆盖 |
| 5 | 先进封装（CoWoS/2.5D） | 国产缺口 30-40% | 重要 | 候选 REL-017 |

**BOM 判断**：加速芯片是 AI 服务器绝对价值中心，但**价值最高层（英伟达/TPU）不可投，可投层（国产设计公司）不稀缺**——这个分离比 NODE-004/005 更极端，直接决定本 Node 的 Alpha 结构（见 Step 7）。

**暗线 4 纠偏（口径冲突清单）**：

1. 博通 ASIC 份额：80-85%（摩根大通）vs 55-60%（行业机构综合）——口径基期与"高端/整体"范围不同；
2. 英伟达中国份额 2026：12%（集邦）vs 8%（Bernstein）——均指芯片口径，取 8-12% 区间；
3. N+2 良率：2025 年"刚爬过 50%"（长桥引述）vs 专家口径"量产良率普遍仅 30-40%"——**若低位为真，存货减值是全行业风险**（海光存货已达 75 亿）；
4. 昇腾 2026 出货：全系列 150-200 万颗（头条）vs 130 万颗（爱股票）vs 华为 910C 目标 60 万颗（英文媒体）——差异 3 倍，内部结构（910B/C/950）口径不一；
5. 中国 AI 芯片市场：集邦 120 亿美元 vs 灼识 2164 亿元——芯片 vs 加速卡整机口径（相差一个数量级）；
6. 思元 690"性能直逼国际一线"（KOL）vs 昇腾 910C 单卡 BF16 约为 B200 的 1/3（aiexpert）——国产单卡与全球旗舰仍有 1-2 代差距，"逼近"指向显存配置而非算力密度。

**与 NODE-004/005 的三连镜像**：OCS 的赛微（MEMS 代工最稀缺、财务最差）、oDSP 的烽火（相干唯一量产、利润连降）之后，本 Node 出现第三种形态——**稀缺层本体（中芯）可投但估值极高且纯度低，设计层可投且兑现强但不稀缺**。"稀缺层排序≠公司排序"至此升格为三类案例：技术稀缺财务差 / 稀缺本体纯度低 / 兑现之王不稀缺。

**暗线 2（新旧龙头交替）**：全球——英伟达（旧王）vs TPU/ASIC 阵营（挑战者），2027 年出货反超为大摩/摩根大通共同信号，但收入口径英伟达仍占 80%+（出货≠价值）；国内——英伟达（让出者）→ 华为系（46%→56%）+ 寒武纪/海光（上市公司梯队），交替已在发生而非预期。

### Step 8 失败条件

1. **H200 恢复对华销售（最锋利反证）**：2025-12 美方已释放 H200 重启信号。若大规模放开，国产芯片"无替代可选"的强制逻辑弱化为"性价比可选"——DeepSeek 曾弃昇腾回 H800 的插曲证明生态粘性真实存在。对冲：信创名录（2026-05-26 九款入册）+ 2027 底 2+8+N 强制替代时间表构成政策底。
2. **中芯产能爬坡不及预期**：260 万颗天花板锁死全行业出货；Q4 扩产（+50%）若因设备/良率延期，所有设计公司营收预期同步下修。良率口径冲突（50% vs 30-40%）未决——若低位为真，存货减值潮将先于营收证伪出现（海光存货 75 亿已亮黄灯）。
3. **ASIC 化挤压通用 GPU 在中国重演**：产能排产优先级已向昇腾/平头哥/昆仑芯倾斜（大厂背书者先吃）；摩尔/沐曦等纯 GPU 厂商在产能谈判桌上天然劣势。
4. **估值风险（本 Node 最当下的风险）**：板块 PE 180-200+；寒武纪市值 6590 亿已计入 2027 年百亿级利润预期；摩尔/沐曦流通盘 4-6% 的筹码结构使任何解禁/风吹草动都会放大波动。60 日板块普跌 8-24%——市场正在检验估值。
5. **需求证伪**：三家 CSP 资本开支（2000/1200/3800 亿）若在 2027 收缩，叠加推理 ASIC 化单价下行，芯片层量价双杀。
6. **技术代差不可收敛**：国产单卡 BF16 仍为 B200 的 1/3；N+3（等效 5nm）若量产延期，1-2 代差距固化，国产芯片只能承接推理侧。

### Step 9 下一步研究动作

1. **产能配额公告级核验**（补本 Node 最大短板）：中芯季报资本开支与先进制程收入指引；寒武纪/摩尔/沐曦中报"存货+预付款"与晶圆采购披露——反推各家实际拿到的产能；
2. **昇腾产业链 820 亿的收入落点**：整机（神州数码/烽火/拓维信息）、液冷、PCB——超节点 BOM 剩余候选层的切出预研；
3. **跟踪信号清单**：①H200 对华销售政策变化（本 Node 第一反证）；②中芯 Q4 扩产与 N+3 量产进度；③摩尔线程/沐曦解禁时间表；④大摩 2027 TPU 反超模型的季度修正；⑤寒武纪 Q3 营收（全年 135 亿目标进度）；
4. **关联 Node 候选**：先进封装/CoWoS 国产化（长电/通富/盛合晶微，REL-017 目标）——制造稀缺层的另一半，且宫主已有盛合晶微卖飞复盘（关联经历）。

## 路由反馈（沉淀给路由表）

1. **系统级 Node BOM 分解范式定型**：NODE-003（系统）→ 互连层切出 004/005 → 计算层切出 006。与"候选 REL 粒度切分"（REL-007/010 案例）并列的第二种切分范式：按 BOM 价值层切。剩余候选层（存储已专研、电源液冷、整机）按需再切。
2. **稀缺层≠公司排序第三案例升格为三类形态**：技术稀缺财务差（赛微/烽火）→ 稀缺本体纯度低（中芯）→ 兑现之王不稀缺（寒武纪）。路由表常设提醒应改写为："稀缺层与公司排序的分离有三种形态，分别对应三种仓位策略"。
3. **产能分配类事实的信源天花板**：N+2 配额（华为 43%/寒武纪 9-11%）永远只有媒体口径，中芯不披露。此类"结构性关键但永无 A 级证据"的事实，标注方式应为"多源交叉的 B/C 级共识"而非等待 A 级——同时把财报侧证据（存货/预付/资本开支）作为代理指标定期反推。
4. **财报密度五 Node 之最**：2026 中报季与本 Node 研究窗口重合，EVD-084/085/094 全为 A 级——Node 研究时机上贴近财报季可显著提升证据质量，路由表可加"财报季优先"提示。
5. **市场口径的数量级陷阱**：灼识 2164 亿（加速卡）vs 集邦 120 亿美元（芯片）相差一个数量级——"AI 芯片市场"这个词本身必须先问口径（芯片/卡/整机），五 Node 以来最极端的口径教训。
6. **次新股筹码结构首次成为排序权重**：摩尔/沐曦流通盘仅 4-6%，"总市值"完全失真——公司宇宙表新增"流通市值"字段为必填项。
