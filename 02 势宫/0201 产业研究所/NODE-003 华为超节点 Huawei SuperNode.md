## 2. 九问结论

### Step 1 Scope

- **市场**：中国（A 股映射）+ 华为产业链全球辐射（俄罗斯/韩国/马来西亚海外订单外溢）
- **主题**：国产 AI 算力系统级架构——超节点
- **时间窗**：3-12 个月（2026Q4 Atlas 950 量产 → 2027 大规模放量）
- **产业链位置**：超节点是**系统集成层产品**，承上启下：上承 AI 芯片（昇腾）+ 存储（HBM/HiZQ），下启云厂商/智算中心，侧连互联（交换芯片/连接器/光模块）、液冷、载板、电源、整机 ODM

**范围界定**：本 Node 研究"华为超节点"这个系统产品及其 A 股可投标的产业链；华为自研部分（昇腾芯片、灵衢协议、HiZQ 存储）作为稀缺层背景，不直接映射 A 股。

### Step 2 System Change

**核心变化：AI 算力架构从"横向堆卡"转向"纵向耦合成一台巨型计算机"。**

| 维度 | 旧架构（8 卡服务器时代） | 超节点架构 |
|---|---|---|
| 互联 | 网络扩展（Scale-Out），跨机通信走以太网 | 柜内 Scale-Up，MatrixLink/灵衢 UB 统一总线，全对等互联 |
| 通信时延 | 微秒级 | 百纳秒级（Atlas 950 NPU 往返 3μs） |
| 内存 | 各卡独立 | 统一内存编址（CloudMatrix 384 内存 = NVL72 的 3.6 倍） |
| 算力密度 | 单机柜 ~8 卡 | 单机柜 64-1024 卡（曙光 scaleX640 单柜 640 卡） |
| 散热 | 风冷 | 全液冷（单柜 100-120kW，风冷失效） |
| 通信瓶颈 | MoE 架构下 All-to-All 通信耗死算力（MFU <60%） | 强耦合通信时延压缩，推理效率 +1.23~1.50 倍（华泰测算） |

**物理约束**：互联带宽、通信时延、内存带宽、功耗密度（散热）。

**驱动因素**：
1. 模型参数膨胀：Kimi K3 已达 2.8 万亿参数；MoE + Agent 成为主流，通信密集型负载使传统 8 卡服务器网络扩展无法满足
2. 单卡代差难补：昇腾 910C 单卡 = H100 的 60% 推理性能 → 用系统级互联的"运力"弥补单卡"算力"代差（CloudMatrix 384 系统级 BF16 性能反超 NVL72 达 1.7 倍）
3. 供应链断裂：英伟达高端芯片禁售（H20 停售），国产芯片必须顶上——昇腾 910C 2025 出货 81.2 万颗（IDC 口径，国产第一）
4. 政策牵引：上海要求新建智算中心国产芯片占比 >50%，北京 2027 年 100% 自主可控；《超节点定义与实践白皮书》（鹏城实验室+全球计算联盟）首次统一行业标准

**暗线 1（受损方）检查**：
| 受损方 | 受损机制 | 程度/时间线 |
|---|---|---|
| 英伟达（中国） | 高端禁售 + 国产替代，份额 2024 年 ~70% → 2025 年 55%（IDC） | 已发生，持续 |
| 传统 8 卡服务器架构 | 超节点替代，通信墙/存储墙不可解 | 2026 起结构性 |
| 传统风冷温控 | 单柜 100kW+ 风冷失效，被液冷替代 | 已发生 |
| 海外互联供应商（TE/Molex/Amphenol、博通/迈威尔交换芯片） | 华为链国产替代（华丰/中航光电、盛科） | 进行中 |
| 海外光模块（在华为链） | 华工/光迅/中际旭创国产供货 | 进行中 |

**暗线 3（周期 vs 结构）判定**：**结构性为主**——算力架构范式迁移（Scale-Up 成为主流方向，行业标准已统一），叠加国产替代刚需。但注意两点周期性：① 资本开支周期（2026H2 放量、2027 大规模上量是券商共识节奏，若 capex 削减则兑现延后）② 板块估值周期（8 月进入中报验证期，主题定价切向业绩锚定价）。

### Step 3 Value Chain

**产业链层级（下游 → 上游）：**

```
云厂商/智算中心（阿里/字节/腾讯/移动/电信，运营商集采）
        ↓
超节点系统集成（华为 Atlas 950 SuperPod / 中科曙光 scaleX640 / 浪潮元脑 / 紫光新华三 UniPoD）
        ↓
整机 ODM（高新发展-华鲲振宇 / 拓维信息 / 神州数码 / 四川长虹 / 华勤技术）
        ↓
【互联层：最大增量赛道】交换芯片（盛科）/ 224G 连接器（华丰）/ 光模块与光引擎（华工/光迅/中际旭创/天孚）
        ↓
【芯片层：价值量最大但华为自研】昇腾 950（海思）+ 自研 HiZQ 存储
        ↓
先进封装与载板（盛合晶微 TSV / 长电 XDFOI / 通富类CoWoS / 深南 FC-BGA / 兴森 ABF）
        ↓
【基础设施层】液冷（申菱/川润/高澜/英维克）/ 电源（泰嘉/欧陆通/杰华特）/ PCB（沪电/生益）
        ↓
上游材料与制造（中芯国际 7nm / 前驱体 NODE-002 / HBM NODE-001）
```

**BOM 结构树（8192 卡 Atlas 950 满配单套，多口径交叉）：**

| 组件 | 口径 A（BOM 4.4 亿，外协视角） | 口径 B（系统造价 5.2-5.6 亿，全价值视角） | 价值分级（暗线 5） |
|---|---|---|---|
| 昇腾芯片 + 自研存储（HiZQ） | 35%（1.54 亿，华为自研） | 61.1%（3.30 亿） | **超重要**（自研，A股不可投） |
| 光模块/光互联（含 OCS） | 光模块 20%（0.88 亿） | 光互联 16% + OCS 8%（1.30 亿） | **超重要**（最大外部增量） |
| 高速交换机/交换芯片 | 12%（0.53 亿） | 并入光互联口径 | **重要** |
| 整机集成（ODM） | 20%（0.88 亿） | 含于系统造价 | 配套（低毛利） |
| 液冷 | 5%（0.22 亿） | 7%（0.38 亿） | **重要**（刚需但多供应商） |
| PCB/载板/背板 | PCB 3% + 载板（单列） | PCB 6%（0.32 亿） | **重要** |
| 高速连接器 | 3%（0.13 亿） | 2.2%（0.12 亿） | **重要**（小体量高壁垒） |
| 电源/结构件 | 2%（0.09 亿） | 1.7%（0.09 亿） | 配套 |

> **口径差异说明**：口径 A 按"外协拆分"视角（华为自研芯片 35%，外部供应商分 65% ≈ 2.86 亿）；口径 B 按"系统全造价"视角（含华为自研部分全部价值）。两口径的**外部可投标的部分高度一致**（A：光 20%+交换 12%+液冷 5%+PCB 3%+连接器 3%+电源 2%+整机 20% = 65%；B：光 16%+OCS 8%+液冷 7%+PCB 6%+连接器 2.2%+电源 1.7% ≈ 41% 的系统造价 × 5.4 亿 ≈ 2.2 亿）。

**BOM 内价值分级结论**：互联（光模块+交换芯片+连接器）合计占外部可投标 BOM 的 **35-40%**，是芯片之外最大的增量赛道，且是"凭空长出来的市场"（传统架构里几乎不存在）——这是本 Node 最核心的产业判断。

**单套价值量锚点**：8192 卡满配单套 4.4~5.6 亿元（多口径）；单芯片散热+互联价值量约 1.5 万元（KOL 口径，未权威证实）；2026 年国内超节点出货 1.1-1.8 万柜（申万/国联口径）→ **2026 年市场总量 500-1000 亿元区间**。

### Step 4 Scarce Layer（稀缺层排序）

先排层级，再排公司。按"供应商数量少 / 认证壁垒高 / 扩产难 / 业绩兑现确定性"排序：

| 排序 | 稀缺层 | 卡点逻辑 | A股可投性 |
|---|---|---|---|
| 1 | **昇腾芯片 + 自研 HiZQ 存储** | 华为海思独占，全栈自研，价值量占比 35-61% | 不可直接投（映射到封测/载板） |
| 2 | **高速互联（灵衢 UB 生态）** | 国产交换芯片/224G 连接器/光引擎均为少数供应商；认证周期长、进入难替换；占外部 BOM 35-40% | ✅ 盛科/华丰/华工/光迅/天孚/中际旭创 |
| 3 | **先进封装 + 载板** | 昇腾 950 两段式封装：TSV 中介层（盛合晶微国内唯一量产）+ 类 CoWoS（长电/通富）+ FC-BGA 载板（深南 60%）；昇腾 81 万→200 万颗的必经环节 | ✅ 盛合晶微/长电/通富/深南/兴森 |
| 4 | **液冷** | 单柜 100kW+ 刚需，认证壁垒中等；多供应商格局（申菱/川润/高澜/英维克），无一家独大 | ✅ 申菱/川润/高澜/英维克 |
| 5 | **整机 ODM** | 进入门槛低、毛利薄（3-17%）、订单波动大 | ⚠️ 高新发展/拓维/神州数码 |

### Step 8 Failure（什么情况说明判断错了）

1. **昇腾出货不及预期**：2026 年目标 160-200 万颗（多口径），若 Q4 Atlas 950 量产跳票或全年出货 <150 万颗，整个产业链预期下修
2. **超节点渗透率不及预期**：2026 年渗透率仅 ~15%（国海），若全年仍 <10%，市场空间测算（500-1000 亿）无法兑现
3. **互联路线变化**：光→铜混合方案比例调整、协议标准变化（灵衢 vs 其他）、OCS 方案替代——导致连接器/光模块订单结构变化
4. **资本开支周期回落**：互联网厂商 AI capex 削减，超节点采购占算力采购 3-4 成的基本盘松动
5. **华为供应商再分配**：多供应商导入（中航光电/航天电器/意华进入 224G 认证），稀释华丰等现有份额
6. **估值已透支**：盛科 PB 81、兴森 PE 440、拓维 PE 603、光迅 PE 157——板块已计入大量乐观预期，中报若不达则戴维斯双杀
7. **海外地缘反制**：若海外对华为芯片供应链进一步封锁，或海外订单（俄/韩/马）受制裁影响取消

## 6. 路由表迭代反馈（第三个 Node 实战记录）

1. **系统级产品 Node 首次实战**：前两个 Node 是材料/器件级（HBM、前驱体），本 Node 是系统集成级产品——**Step 3 价值链层级显著更长**（芯片→互联→封装→基础设施→整机→系统），BOM 拆解必须依赖多口径交叉而非单一来源；**"系统级 Node 的 Alpha 映射天然是多层级的"**，一级/二级 Alpha 分属不同稀缺层（互联 vs 载板），与器件级 Node 的单点映射不同。
2. **KOL 份额口径大爆发，纠偏成本上升**：本 Node 遭遇前所未有的"唯一/第一/份额"说法密度（液冷 4 家互相矛盾、交换芯片 90%、基板 60%、份额反超英伟达）——**处理规则升级**：凡是"独供/第一/XX%"且无券商或公司披露支持的，一律标注 KOL 口径；多家来源冲突时，以 IDC/券商等可溯源口径为准，或判定"多供应商、无权威数据"（如液冷）。
3. **"昇腾反超英伟达"证伪**："2026Q1 昇腾份额 37% 反超英伟达 19%"广泛流传但无权威来源；IDC 官方口径英伟达 55% 仍居首。**验证了暗线 4 在"国产替代叙事"上的高发区属性**——越是民族情绪强的叙事，越要回到权威第三方数据。
4. **概念池稀缺度信号再次出现**（NODE-002 反馈 6 的复用）：东财"超节点"概念 162 只 vs 真卡脖子 ~8 只——概念越宽、真标的越少，资金越聚焦也越拥挤。162 只概念本身说明板块已进入"概念扩散期"，警惕纯概念股。
5. **市场空间多口径成为标准动作**：三套券商口径（华泰 3414/6250 亿、国海 11089 亿）+ 机构交叉（500-1000 亿 2026）并存——延续"给区间+标来源"原则，并新增"口径差异说明"（整柜 vs Scale-Up 架构、是否含全栈配套）。
6. **资金流作为 Trading OS 交接信号有效**：光迅/华工/兴森 5 日主力大幅流入与板块"业绩锚定价"切换期共振——资金面数据在系统级主题上的区分度高于器件级（板块内部轮动明显：中科曙光流出 38 亿 vs 光迅流入 23.7 亿 10 日）。
