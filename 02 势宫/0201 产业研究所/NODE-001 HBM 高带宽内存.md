## 2. 九问结论

### Step 1 Scope

- **市场**：A 股为主，映射全球（SK海力士/三星/美光/长鑫）
- **主题**：HBM 高带宽内存——AI 算力架构下的内存带宽瓶颈环节
- **时间窗**：2026 H2 — 2027（3-12 个月）
- **全景**：妙想 stock-screen 命中「高带宽内存」概念 **31 只**（北方华创 5581 亿居首）；westock 聚源概念板块 pt02GN2272 **54 只**成分股（口径更宽，含设备/材料/封测/检测）

### Step 2 System Change

**系统变化**：AI 训练/推理算力扩张 → GPU 内存带宽需求指数级增长 → HBM 代际升级（HBM3E→HBM4）、堆叠层数提升（12 层→16 层→更高）→ TSV 密度、材料纯度、设备精度要求同步抬升。

**关键物理约束**：带宽（内存墙）、堆叠良率（TSV/键合）、材料纯度（前驱体/介电材料）、散热。

**证据（B 级）**：
- 财信证券 8/13 存储深度报告：《AI引爆存储需求，供给约束支撑行业高景气周期》
- 国金证券 8/3《长鑫科技深度：冉冉升起的中国DRAM龙头，充分受益存储高景气周期》
- 诚通证券 8/17 宏观周报：继续布局 AI 主线及景气度边际改善行业

> **暗线 3 检查点（周期 vs 结构性）**：HBM 需求是**结构性**（算力架构改变，非短期景气）；但存储行业整体仍具**周期性**（传统 DRAM 价格波动）。HBM 部分按结构性 Alpha 持有逻辑，传统存储部分按周期 Alpha 收割逻辑——两者风控策略不同。

### Step 8 Failure（什么情况说明判断错了）

1. **技术路线替代（中长期最大风险）**：玻璃基板路线若成熟，将改变封装与互连体系——6-7 月密集报道"台积电/三星/英特尔集体押注玻璃基板""千亿替代空间"。短期 3-5 年 HBM 仍是主流，但**这是 HBM Node 与宫里 Glass Bridge/TGV 研究的连接点**（关系索引待建）
2. **AI 资本开支放缓**：若算力扩张不及预期，HBM 结构性需求逻辑松动（叠加存储周期性，双杀风险）
3. **雅克特定风险**：商誉 20.9 亿减值、有息负债偏高、2026Q1 增速背离待核、财务资助（关联交易）监管关注
4. **地缘/出口管制**：半导体材料管控升级可能影响海外客户
5. **估值风险**：现价已超一致预期目标价 46%，拥挤度高（两只异动公告佐证）

> **暗线 1 检查点（受损方分析）**：HBM 结构性扩张的受损方——① 传统 GDDR 显存方案（带宽需求被 HBM 虹吸）；② 跟不上代际升级的旧 HBM2E 产能（快速贬值）；③ 有机载板/ABF 膜体系（玻璃基板替代的潜在受损方，味之素砍单已是前兆信号）；④ 消费电子存储（HBM 挤占产能 → 涨价压力传导）。

## 6. 路由表迭代反馈（首个 Node 实战记录）

> 对应路由表第七节操作清单第 5-6 条："记录哪里不顺手 → 迭代协议"。

1. **妙想 stock-screen 偶发返回空**：同一 keyword 首次调用返回空表格，重试成功（命中 31 只）。→ 命令层需加重试机制。
2. **妙想 query 宽泛问法失效**："HBM 产业链上下游结构"返回空表（dataTableDTOList 为空）；改为具体指标问法（"雅克科技最近三个报告期的营收、净利、毛利率"）才命中。→ 映射表应注明"问具体指标，不问宽泛概念"。
