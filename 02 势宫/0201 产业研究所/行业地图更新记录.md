## 一、记录口径

### 1.1 变更类型

| 类型 | 含义 | 典型信源 |
|---|---|---|
| 新闻 | 行业动态、事件、政策、传闻 | 财经媒体、通讯社 |
| 研报 | 券商/机构研究观点、目标价、评级 | 券商研报、妙想 news-search（REPORT） |
| 公告 | 上市公司披露 | 交易所公告、westock notice |
| 数据 | 价格、产能、出货、份额、财务等可量化事实 | 财报、产业数据、第三方统计 |
| 产品 | 新品发布、量产、送样、认证 | 厂商发布、展会 |
| 技术 | 工艺/架构路线变化、良率突破 | 技术论文、产业媒体、厂商技术日 |
| 关系 | Node 间 REL 关系新增/转正/修正 | 分诊判定 |
| 证伪 | 命中某 Node Step 12 失败条件 | 任何信源 |

### 1.2 影响判定

| 判定 | 含义 | 处置 |
|---|---|---|
| 确认 | 印证既有结论 | 写入证据索引，Node 正文不动 |
| 强化 | 使既有结论更成立（缺口扩大、进度提前等） | 更新对应 Step 段落的数值/时间 |
| 削弱 | 使既有结论成立度下降 | 更新段落并**加注存疑标记** |
| 证伪 | 命中 Step 12 失败条件 | **不自动改结论** → 进待裁决队列，等宫主裁决 |
| 待观察 | 单次信息不足以判断方向 | 只登记，不动结论 |
| 无实质影响 | 与 Node 判断无关 | 只登记，可批量折叠 |

### 1.3 写入规则（硬）

1. **结论不动原则**：除"确认/强化"外，任何改动 Node 十三步**结论句**的更新，一律先入待裁决队列，不自动改写。日更不能让研究结论逐日漂移。
2. **证据先于观点**：每条实质更新必须挂载证据（EVD-XXX），编号跨 Node 全局连续，从路由表证据索引当前最大值 +1 起编。
3. **去重优先**：命中已有事实 → 升级原证据来源，不新建条目（路由表 4.1 / 4.3）。
4. **一信息多 Node**：横向传导记入本文第三节，各 Node 各自记一行并互引。
5. **分诊歧义即暂停**：多 Node 命中 / 部分命中 / 需新建 Node → 按路由表 Step 3 提交分诊报告，等宫主批准。
