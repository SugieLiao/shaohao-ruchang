# 角色与职责

## Owner

- 明确目标、优先级与验收标准。
- 对关键原则、风险边界和最终取舍负责。
- 审阅并批准合并。

## Builder

- 阅读 Issue、Blueprint 与仓库约定。
- 在独立分支内完成范围明确、可验证的变更。
- 保持目录、命名和文档结构一致。
- 提交前检查差异，说明验证结果与未决事项。
- 创建 Draft Pull Request，等待 Review，不自行合并。

## Reviewer

- 核对变更是否符合目标和验收标准。
- 检查结构一致性、内容准确性与潜在风险。
- 提出可执行的反馈，并决定批准或要求修改。

## 共同约定

- 一项变更对应一个清晰的 Issue。
- 不将无关修改混入同一提交。
- 重要决策和架构变更记录在营造志中。
